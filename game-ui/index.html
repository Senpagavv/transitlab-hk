TransitLab · 修地铁

    在真实的 2026 年香港上画新地铁线，用完整的交通模型算出：谁会坐、省多少时间、路上少多少车、值不值。

    像规划师一样想：四个问题
    1. 人在哪？打开「人口」「岗位」图层，颜色越深越多。
    2. 要去哪？打开「主要人流」：早高峰坐公交、人多又走得远的方向，箭头越粗人越多。
    3. 站放哪？在地图上随便点一下，右边会出「站点卡」：周边 800 米多少人、跟哪个现有站差不多。
    4. 怎么接？把站点在现有港铁站旁边（150 米内）就自动变成换乘站。

      欢迎来修地铁

      这是真实的香港：455 个分区、750 万人、早高峰每小时 140 万人次坐公交，都来自政府数据并校准过。

      1. 看图层：橙色是离港铁远的人，越深越多。
      2. 点「画一条新线」，在地图上一下一下点出车站，站和站之间自动连直线。
      3. 点「开始算」，模型会一轮轮算：谁改坐新线、去哪的人变了、路上少了多少车。
      4. 看账本：值不值、为什么。改一改再算，分数会变。

      情境题模式有一道题和打分；自由世界随便画。
