🛸 外星人降临启德

目标：21:00 外星人离开前，让尽量多的人赶到启德领礼物。

你只有一个工具：巴士专线（0 / 4）

  1. 鼠标停在一条粗线（干道）上：马上预演"现在给它开专线会怎样"——哪些路变顺（绿）、哪些路变堵（红）、最后能多送多少人。
  2. 点一下就开专线（5 分钟后生效）；再点一下关掉。
  3. 专线上巴士不堵，坐巴士的人变多；但私家车少一条车道，会绕去别的路。

怎么看

  • 干道：畅通 → 堵死（细线是不能开专线的连接路）
  • 私家车 / 的士　巴士
  • 想来、还在家的人　放弃了
  • 港铁站外排队

人口、道路通行能力和车道数、平日的公交时间来自 2026 年香港数据；想来的人数和外星人是游戏设定。

🛸 外星人降临启德！

傍晚 6 点，外星飞船停在启德上空派礼物，9 点离开。消息从启德往外传，全港约 58 万人想赶来——开车、坐巴士、坐港铁、走路。路会堵，港铁会挤，路上要花的时间比平时多太多，人就放弃不来了（放弃的不会再来）。

你能做的只有一件事：给干道开巴士专线（最多 4 条）。

  • 鼠标停在干道上 → 预演开专线后，全港各条路会怎么变；
  • 点一下 → 开（或关）专线。
