## 第 1 讲：Introduction

来源：`CA5236_Week1_Introduction_2026 (1).pdf`。

| PDF 页 | 方程、模型、术语 | 讲义确切范围和本工程关系 |
|---|---|---|
| p.18–19 | 派生交通需求；土地利用—交通反馈环 | 活动地点创造出行需求，交通可达性又影响用地；对应 21–27b 与土地侧 16/36–38。讲义展示反馈概念，没有给可执行迭代式。 |
| p.22–23 | mobility 与 accessibility；可达性的四个组成（交通、土地利用、时间、个人） | 可达性不等于单纯速度；17/18 的时间矩阵只覆盖交通组成。 |
| p.24–26 | 5Ds 建成环境因素与相关实证效果 | 密度、土地用途多样性、设计、目的地可达性、到公交的距离等为解释框架；工程未把 5Ds 全部估计为弹性系数。 |
| p.27 | induced demand 诱发需求 | 交通改善可改变出行量/距离；现有 27b 只反馈阻抗，不等于完整诱发需求模型。 |
| p.29–30 | 土地增值回收、公交导向开发（TOD） | 属政策与空间发展概念；37/38 的容量及房价是输入，并非课件中的政策评估公式。 |
| p.33–36 | 四阶段模型、交通影响评估、长期规划、四阶段限制 | 四阶段依次是产生、分布、方式选择、分配；讲义说明顺序模型、交通分区聚合等限制。 |
| p.37–38 | 新数据来源、可达性图 | 05/07/09 等以行政、探测器、GIS 数据代替部分问卷；17/18 为时间可达性底表。 |
| p.39–42 | 轨迹数据、共享/自动化与新技术 | 背景术语，工程沙盘 28–35 仅作情景，不等于实证预测。 |

**公式盘点：**第 1 讲主要讲概念与流程，没有给 BPR、重力平衡、Wardrop 或公交最优策略的可直接照搬方程。

| PDF 页 | 方程、模型、术语 | 讲义确切范围和本工程关系 |
|---|---|---|
| p.6–10、p.13–26 | 行政城市、连续建成区、密度门槛、城乡分类 | “城市”边界随定义变；模型用 455 个 traffic zones，不能误当行政区。 |
| p.28–29 | 单中心城市、Alonso–Muth–Mills 基准；通勤距离 | 距市中心越远，通勤成本越高是基准假设；香港多中心，因此 22 用 OD 阻抗而不是单一 CBD 距离。 |

| p.31–34 | 住房竞价梯度、开发强度、运输成本下降使梯度变平；单中心局限 | 课堂是机制解释；38 没有估计地价梯度，37 的地积比也不等于内生开发强度。 |
| p.35–55 | 交通技术与城市扩展、铁路/电车/汽车改变有效距离 | 历史案例；新线路的动态土地响应只在 game-demo 用简化弹性示意。 |
| p.56、p.62 | 城市变化的快慢时间尺度 | 交通行为快、建筑和土地供给慢；本工程 2026 基准为静态切片。 |

## 第 3 讲：Transport Demand Forecasting

来源：`CA5236_Lecture 03.pdf`。**页码是 PDF 页，不是印刷页脚**（该文件页脚在不同章节重启）。

| PDF 页 | 方程、模型、术语 | 对照要点 |
|---|---|---|
| p.4–7 | 建成边界、平均密度、中心/边缘梯度 | 空间变化有不同量尺；16/36 用交通分区和地类格网。 |
| p.5 | 负指数密度梯度 D(x) = D₀ × exp(−β × x) | D 密度，x 距中心距离；工程没有拟合此式。 |
| p.9–10 | 收入的交通与住房双通道；住房需求收入弹性 ε_H,Y=(%Δ H)/(%Δ Y) | 工程没有拟合该弹性；game-demo 的人口弹性 0.5 也不是此式。 |
| p.11–15、p.23–27 | Land Use–Transport Interaction、交通主导/用地主导、城市蔓延 | 反馈是长期机制；27b 只做短期拥堵时间回代。 |
| p.29–32 | 运输供需、预测高估/低估、研究范围 | 先界定网络、土地及方式，后校准观测。 |
| p.34–37 | 传统四阶段框架、总量控制、OD 调查及其方法 | 20 从 TCS 提取参数，21 控制分目的总量。 |
| p.38 | 总出行数：各人群人数乘目的出行率再求和；总出行等于各区产生/吸引总和 | 讲义的数学字形在文本抽取中损坏，旁注明确 k 是人群类别，出行率乘人数；对应 21。 |
| p.39–40 | 单位率产生/吸引：土地类型面积 × 单位出行率再求和 | 讲义有住宅/办公/商业示例；21 的产生按人群，吸引按岗位/学校/楼面，属变式。 |
| p.41 | 线性回归 G_i=β_0+Σ_mβ_mX_im、A_i=γ_0+Σ_mγ_mX_im | 讲义举人口、收入、车辆、CBD 距离；21 吸引采用非负最小二乘（NNLS）以避免负吸引量。 |
| p.42–43 | OD 出行分布；现状格局增长法 | 本工程选择重力法，没有直接等比例放大旧 OD。 |
| p.44 | 重力法 T_ij∝ G_i^α A_j^γ f(c_ij) | 课堂“推/拉/阻抗”概念；22 加双向配平因子以严格守恒产生/吸引。 |
| p.45 | 幂式 c^(−γ)、指数式 exp(−β × c)、复合式 c^(−γ) × exp(−β × c) 阻抗 | 22 用指数式；课堂的 0.2、2 是示例，并非香港校准值。 |
| p.46 | 取自然对数后用普通最小二乘（OLS）估重力参数 | 22 实际用二分调 β 以匹配调查平均时间，再 Furness 配平；不是课堂的 OLS。 |
| p.47–50 | 方式份额、trip interchange 与 trip end 两种模型、服务/时间/票价/拥堵、S 形份额曲线 | 23 是 OD 级 trip interchange，采用离散选择 logit，课堂该讲尚未写出 logit 方程。 |
| p.51–53 | 网络分配、分批增量分配、速度/密度/流量等服务水平 | 27 的均衡分配是对增量示意的算法扩展；BPR 曲线在这三页未给方程。 |
| p.54 | 四阶段总结 | 四步串接的示意。 |

## 课件没有给出的本工程算法

BPR 的加权最小二乘参数拟合、双约束 Furness、Beckmann–Wardrop 用户均衡、BFW、MSA 回代、GEH、Spiess–Florian 公交最优策略、货车 rho 及隧道队列，**在提供的第 1–4 讲 PDF 中未找到方程**。道路/公交网络分配与此最接近的后续大纲为**第 9 周将讲：Transportation Network Modelling**；这只说明主题相近，不能预言课件会讲哪条公式。上述算法在总目录中按“课外（教科书标准内容）”标注；可供延伸读的通用著作为 Ortúzar & Willumsen《Modelling Transport》、Sheffi《Urban Transportation Networks》。
