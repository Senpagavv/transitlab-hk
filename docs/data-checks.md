# 数据核查记录

## 2026-09-15 · 底图建筑是否缺失？

**问题**：地图上建筑集中在市区，山上几乎没有建筑，是不是漏了？

**结论：没有漏。**山上建筑少是香港的真实情况；村屋等小型建筑在低缩放级别下被官方地图简化，放大到 18 级会全部显示。

### 核查方法与结果

1. **数据层面**：解码地政总署矢量瓦片，统计每类建筑（`_symbol` 0/1/2）在数据中的数量，与样式实际绘制的类别对比，**没有任何类别被遗漏**。
2. **与航空照片对比**（同一视野，地政总署航拍）：
   - 太平山顶、川龍村：地图建筑与照片一致；大片林地确实没有建筑。
   - [太平山顶](images/building-check-peak.jpg) · [川龍村](images/building-check-chuen-lung.jpg) · [林村 15 级](images/building-check-lam-tsuen.jpg)
3. **与地政总署官方图片底图对比**（林村 17 级）：我们的矢量地图与官方底图显示的建筑**完全相同**，差异来自官方制图本身。[三图对比](images/building-check-lam-tsuen-z17.jpg)
4. **放大到 18 级**：出现 1:1,000 比例尺的详细建筑（门牌号、"TS" 临时构筑物、"WIP" 施工中），与航空照片高度吻合。[林村 18 级](images/building-check-lam-tsuen-z18.jpg)

### 各缩放级别显示的建筑数据

| 缩放级别 | 建筑数据比例尺 | 说明 |
|---|---|---|
| 11–12 | 1:200,000 | 只有大片建成区轮廓 |
| 12–14 | 1:50,000 | 简化，村屋等小建筑大量省略 |
| 14–16 | 1:10,000 | 主要建筑 |
| 16–18 | 1:5,000 | 较完整 |
| 18 以上 | 1:1,000 | 最详细：门牌号、临时构筑物（TS）等 |

### 对项目的影响

底图建筑**只用于显示**。交通模型的人口和就业来自人口普查（按小区统计），不依赖地图上画了多少栋楼。如果以后需要按建筑做分析（例如站点周边楼宇数量），可以直接使用地政总署 1:1,000 建筑数据。
