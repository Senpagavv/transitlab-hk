参数值来源 / 正式版怎么定

做这个演示时发现的三件事

  1. 分数不能用 BCR。英国 TAG 的算法把票务收入从成本里扣掉，票价一高分母就接近零，比值会冲上天，但社会其实变差了。所以分数改用社会净现值，BCR 只作参考。右上「两本账」里有实时对比。
  2. 巴士和新线之间不能全有全无地选。如果谁快就全坐谁，一挤就全体倒戈、下一轮又全回来，迭代来回跳。演示里改成按时间差平滑分配（敏感度 0.25），2–8 轮就稳。算法同学写 F4 和 F9 时要注意这一点。
  3. 巴士少收的票钱怎么算，会明显改变分数。从巴士抢来的乘客，票钱只是从巴士公司挪到地铁公司。演示假设巴士砍班能省回 70%，只把剩下 30% 算成损失。这个比例要组里定。

演示比正式第一版简化的地方：全线一种建造方式（正式版逐段选）；有车和没车的人合成一组；接驳时间用直线距离乘系数，不是现有公交网络的真实时间。

模型全文在同目录的 model.js，函数编号和页面上的 F1–F13 一一对应。人数、造价、速度都是占位数，只用来看清因果关系。
