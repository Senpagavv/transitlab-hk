# 全港沙盘 · 第三版设计（2026-10-15）

> 写给发起人。根据 10/15 的要求：整屏是地图、操作是浮在上面的卡片；不选功能就是看地图；选区放大只算这一片；放大后的状态像前四关。

## 怎么操作
- **默认「看地图」**：拖动平移、滚轮缩放；鼠标停在哪，右上资料卡就显示那里（分区：人口、岗位、早上开车比例、数据来源可信度；路：车流、负荷；站：线路、客流）。
- **选了工具才操作**；再点一次或按 Esc 放下，回到看地图。工具条上方弹出这个工具的卡片：
  - 画线 / 放站：第几条线、新增一条线、列车 ±、这条线花了多少。
  - 选区：点分区（Shift 多选）；卡片里「放大只算这一片」「用第三关玩这一片」「清除」。
  - 改人口：选中分区的人口、小孩、成人、老人、吸引力滑杆。
  - AI：一句话出关卡（原来 AI 页签的内容）。
- **放大只算这一片**：镜头飞到选区，其他地方变淡；计算只让「起点或终点在选区里」的出行重新选择（道路的背景车流照旧），快很多。情境卡显示「范围：观塘一带 ✕」，点 ✕ 回到全港。
- **用第三关玩这一片**：按选区中心切一个 16×12 的关卡（和 AI 出关卡同一个切法），用第三关的玩法打开。
- **跑一轮 / 跑到稳定** 之后，右下结果卡出现：坐新线、少了多少车、塞车减少、省下的时间、看成绩单；「变化 / 之前 / 之后」也在这里。
- **全港数据地图**（顶栏）：一键回到原来 TransitLab Live 的看法。
