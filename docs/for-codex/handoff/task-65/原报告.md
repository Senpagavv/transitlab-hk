## 报错、失败请求与证据边界

- 覆盖页面和实跑关卡未捕获页面 JavaScript 异常；本地游戏资产没有记录到非预期 HTTP 失败。
- 离线 AI 请求的 **503 是按任务故意返回**，控制台对应的 503 不是产品回归。
- 一次正常示范记录中 Google Fonts 样式请求发生 `net::ERR_NAME_NOT_RESOLVED`，浏览器使用后备字体。原始请求 URL 和错误在 `gameplay.json` 的 `m4-2` 记录中；这是外部字体网络失败，不归为本地游戏资产丢失。字体可用性会影响文字宽度，因此手机溢出另有冷启动视口和几何数据佐证。
- 可见正文扫描未发现 `m5.xxx` 这类原始键名。共用编辑器的主题标题、语言辅助标签曾缺四个键，已在允许的文字文件中补齐。
- 已查看浅色 / 深色的关卡、卡片和成绩单证据；没有额外确认到独立的深色主题阻断问题。这里不宣称已经做完逐像素的色彩对比度认证。
