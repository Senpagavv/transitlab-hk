## P1-6 · 提速与逐位核对

采样发现：道路路径在准备阶段已算好，单轮慢点是求解器反复做路径上的矩阵向量乘；另一个热点是每个分区对每个站重复做同一个6格内步行搜索。

本次只做两项：每个分区搜索一次6格内陆地距离，再查询所有站；将热循环里的 TypedArray 迭代器换成索引循环。路径、参数、求解容差、浮点加减乘顺序不变。非整数坐标保留原步行算法。不改变道路路线、不引入跨方案的持久缓存，因此没有缓存失效风险。
