## 第一玩法示范格式 / Mode 1 demo schema

放在 `level.demo`：

```json
{"tiers":[80,130,176],"best":200,"pass":{"opening":[[1,1],[2,1],[3,1]],"moves":[],"score":90},"high":{"opening":[[1,1],[2,1],[3,1]],"moves":[{"r":2,"id":1,"cell":[2,2]}],"score":140},"master":{"opening":[[1,1],[2,1],[3,1]],"moves":[{"r":2,"at":55,"id":1,"cell":[2,2]}],"score":200}}
```

这里只展示字段，不代表这些坐标可玩或分数已验证。`opening` 固定三个候选格，按 A/B/C 排；`moves` 中 `id` 为 0–2、`r` 从 1 开始；无 `at` 是该轮前停顿挪站，有 `at` 是实际 `roundStart` 后多少秒，消耗机动次数。`score` 为结束时 `Game.delivered`。
Structural example only. Opening is the three A/B/C candidate cells. Stop id is zero-based; round is one-based. Omitted at means the break before that round; at means seconds after its actual start. Score is final Game.delivered.

当前 `v7_bus.js` 实为历史 mode4-bus，已新增 `--level` 第一玩法分派；不带 --level 的历史行为保留。第二到四机器人已修复读入 JSON 后又改回内置关卡的问题，并支持只有两个不同地点的地图，不再等不到第三/四个地点。
The historical v7_bus filename actually targets mode4-bus; --level now dispatches mode 1 correctly. Rail bots retain the supplied level and support two-place maps.

第一玩法 `data.js::make()` 未复制 demo；因此 demo.js 只在取方案位置增加 `内置 → D.demo → 当前 registry / active pack 的 level.demo` 回退。未修改 data.js。现有同编号内置方案继续优先，Claude 决定取代旧关卡时需要检查这一点。
Mode-1 plan lookup adds built-in → D.demo → registry/active-pack fallback because the unchanged data loader omits demo. Built-in plans retain precedence for matching keys.

## 安全与已知局限 / Limits

只读 UTF-8 JSON，单个 2 MiB、累计 / ZIP 64 MiB、最多 512 项。ZIP 不落地解压；拒绝穿越、绝对路径、加密、ZIP64、分卷、符号链接、非 JSON、CRC/头不一致和压缩炸弹。资源保护、具体格式、门槛 / 简单方案定义详见 `game-feeder/tools/levels/README-intake.md`。
JSON-only input, bounded file/archive sizes, no archive-path extraction, rejection of unsafe or inconsistent entries. Detailed guards and definitions are documented in README-intake.md.

最好分是搜索找到的下界，不证明全局最优。当前项目快照没有 `v7_tod_plus.js`，使用现有 `v7_tod.js` 完整搜索。部分分段没有独立方案时，示范会越过下一档或共用方案，报告保留实际分数。
Best found is not a global optimum proof. This snapshot has no separate plus bot; the available full TOD bot is used. Demos may exceed the next threshold or share a plan when a score band has no candidate.
