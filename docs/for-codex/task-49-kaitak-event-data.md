# 任务 49：启德体育园大型活动的人流与散场交通——真实数据（给游戏校准用）

## 一、背景
修地铁游戏的新手模式定为「外星人降临启德」（虚构主题），玩家在现有道路上**派特别巴士、划临时巴士专线**，在 3 个游戏小时内把大量人送到 / 送离启德。
游戏里的数字要**先用启德体育园真实的大型活动校准，再往上夸张**；游戏结束时有彩蛋，揭晓「其实这就是启德演唱会散场」，并和真实数字对照。所以真实数据要准、要有出处。

## 二、硬规矩（违反作废）
1. **项目只读**：`F:\transitlab-hk` 不写、不改、不删（可以读、可以 import 运行；不要运行 `pipeline/` 里的脚本）。
2. **只写一个目录**：`%USERPROFILE%\Desktop\TransitLab启德实测\`。
3. 可以上网查公开资料（启德体育园官网、运输署特别交通安排公告、港铁公告、立法会文件、环评 / 交通影响评估报告、新闻报道），**逐项查阅，不要批量抓取政府网站**。
4. **不编造**：每个数字写出处（文件、页码 / 网址、日期）；新闻里的数字注明是报道；推算的写清公式；查不到写「未找到」。

## 三、要查的内容
1. **场馆**：启德体育园各场馆座位数（主场馆、室内体育馆、公众运动场等）、启用日期；2025–2026 年办过的大型活动（演唱会、球赛等）的日期、开始 / 结束时间、入场人数。
2. **散场实况**：新闻、立法会质询、政府回应里，大型活动散场**用了多久**、启德站 / 宋皇台站排队多长、有没有封站 / 限流、出过什么问题；官方有没有「X 分钟内疏散」的目标。
3. **交通安排**：港铁加班车（班次、加了多少）、车站人流管制；**特别巴士路线**（几条、去哪、几辆车、班次、上车点在哪）；的士站位置和车位数；公共运输交汇处的巴士 / 小巴车位数；私家车位数；封路安排；步行路线。
4. **交通影响评估 / 环评**：启德体育园当年的交通影响评估或环评里，对**散场人数、各交通方式比例（港铁 / 巴士 / 的士 / 私家车 / 步行）、散场时间、车站和路口容量**的假设——这是最好的校准依据，尽量找到原文和页码。
5. **容量参数**：启德站、宋皇台站的进闸 / 出闸能力或月台容量；屯马线晚间班次和每列载客；双层巴士载客量、上落客每辆要几分钟、一个上车位每小时能发几辆；的士站每小时能上多少车；附近主要道路（太子道东、启德隧道、协调道等）的通行能力。查不到的写「未找到」。
6. **对照案例**：香港大球场（国际七人榄球赛）、亚博馆演唱会（机场特别巴士）、维港烟花等大型人流的散场速度（每分钟多少人）和交通方式比例，可以帮我们判断启德的数字合不合理。
7. **夸张建议**：根据以上真实数字，给出游戏的「真实档」和「夸张档」建议（例如真实 5 万人 → 游戏 15 万人；真实特别巴士 N 辆 → 游戏车队上限），并说明夸张后玩家会遇到什么瓶颈。

项目里可以用的数据（只读）：启德附近分区人口、港铁各段载客率等，见 `docs/for-codex/task-48-desire-map.md` 第三节的读法（`game.engine.base` / `game.engine.places`）。
