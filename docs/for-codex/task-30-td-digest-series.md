# 五、这个工程的已知坑（**踩过的，别再踩**）

1. **列标签只画在图上、单元格里没有**。这两张表的表头跨好几行、还有合并单元格，
   `pandas.read_excel` 读出来大量 `NaN`。**不要用固定行号索引**——要按内容搜索
   （例如找到含 `"Taxis"` 的那一行来定位列），否则换一期月报就全错。
2. **同一张表里年度块和月份块之间隔着空行**，不能简单 `dropna()` 了事，会把结构信息丢掉。
3. 月份块的"年"只写在该年第一行，后面的行是空的，**需要向下填充**。
4. 所有数字以 `float` 存，不要四舍五入。
