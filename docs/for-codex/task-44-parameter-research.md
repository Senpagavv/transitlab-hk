# 任务 44：查清教学/游戏模式要用的 24 个参数（每个值都要有出处）

## 一、背景
TransitLab HK（`F:\transitlab-hk`）要做一个**教学 + 游戏**的交通规划软件：在真实香港地图上画新地铁线、做站旁开发，模型算客流、塞车、减碳、花费和值不值。
所有数据和参数都按可信度分级（见 `docs/data-tiers.md`）：A 实测 / B 校准推算 / C 依据推断 / D 示意假设。
登记表 `model/registry/data_tiers.toml` 里有 22 个参数状态是 `to_research`（待查），另有 2 个在用的 D 级原型参数要找文献升级，**数值还空着**。你的任务：**逐个找出处、定数值和合理范围**。

## 二、硬规矩（违反作废）
1. **项目只读**：`F:\transitlab-hk` 里不写、不改、不删任何文件。另一个 AI 在开发。
2. **只写一个目录**：`%USERPROFILE%\Desktop\TransitLab参数调研\`（不存在就创建）。
3. **可以上网查资料、下载公开文件**（立法会文件、政府报告、港铁年报、学术论文），但**不要批量抓取政府网站或接口**，每个网站间隔慢一点。
4. **绝不编造**：每个数值都要能追到原文（文件名、机构、年份、网址、**页码或表号**，并摘一句原文）。找不到就写「未找到」，不要估一个数填上。
5. 文中所有换算（例如把 2014 年造价换成 2026 年价格）都要写出公式和用的指数。

## 四、方法要求
- **造价**：每个项目一行：项目名、核准造价（亿港元，原文年份）、长度（公里）、隧道/高架/地面各多少公里（文件有写才填）、车站数、开通年；
  换算到 2026 年价格（用统计处综合消费物价指数，或找到的香港建造成本指数，写明用哪个）；再给出**中位数和范围**。不同建造方式混在一起的项目，写明无法拆分。
- **溢价、弹性类**：每个研究一行：作者、年份、期刊、城市、样本、方法、结论数值；最后给**建议值和范围**，并说明为什么选它。
- **排放系数**：写明年份、口径（直接排放还是全生命周期）、单位。
- 每个参数最后给一行**结论**：建议值、单位、范围、建议级别（A/B/C/D）、可移植性说明（例如"国外研究，用于香港要谨慎"）。
