## 一、最终要的是什么（先读懂再动手）
第五关「全港沙盘」是整个游戏的最后一关：**整个香港是一张格子地图，玩家像前四关一样动手改（画地铁、放站，以后还有巴士站、地点开发、改某区人口），然后看全城怎么变**——哪些人改坐地铁、哪条路少了车、哪里反而更塞。它用来：
1. **自由玩**：自己找香港交通的问题，自己试解法；
2. **挑战**：几个现成的「题目」（真实的痛点），有过关条件；
3. **出关卡**：选一片 / 打一句话，切出一关用第三关玩法玩（Claude 接）；
4. **查数据**：香港现在的真实数字，标清楚来源可信度。
前四关的画风、操作手感是标准：第五关要像「放大版的第三关」，而不是一张数据图。

## 三、要做的（按优先顺序，做到哪写到哪）

### 1. 地图看得懂（最先做）
- **地名一直看得到**，随缩放分三层：全港时显示 18 区区名（大字、半透明）；放大一级显示港铁站名和主要地方（商业区、新市镇）；再放大显示屋苑 / 分区名和路名。名字取 `hk-base.json` 的 `zones`、`stations`、`roads`（中文优先）。
- **画风照前四关**（`v7/mode3-roads/ui.js` 的 `drawBase`、`v7/mode1-bus/ui.js`）：放大到能看清格子时画淡色路带、像素楼（按人口疏密）、写字楼（按岗位）、树丛（郊野）、海；全港缩小时简化成区界、主干路、港铁线。港铁用官方色，站画成圆点 + 站名。
- **片区一点就到**：右边 20 个片区按钮点了缩放过去，片区框高亮，框旁写片区名；地图上片区框一直淡淡地画着。
- 指着一格：小卡片写「这是哪（分区名、区）、住多少人、多少岗位、早上开车几成」。

### 2. 打开就知道玩什么
- 第一次打开（或按「玩法」）弹一张卡：**三步**——①选一个地方（点片区或题目）②画线、放站 ③按「跑」，看这里的人和车怎么变。
- **三道题**（左栏顶部，像前四关的关卡卡片），每道题：一句故事、要达到的数、按了就缩放到那里并显示目标：
  - 「九龍東塞車」：在九龍東畫一條線，讓觀塘道 / 觀塘繞道每小時少 100 輛車；
  - 「北部都會區沒地鐵」：在新田 / 古洞一帶接一條線，讓這一帶坐公共交通的比例升 3 個百分點；
  - 「啟德多五萬人」：（先用現有數據）在啟德附近建線，讓九龍東塞車減少最多。
  - 题目写在 `mode5-sandbox/challenges.js`（格式：`{key, title(三语), story, area, goal:{metric, target, where}, hint}`），以后加题只改这个文件。达到目标就打勾（存本机）。具体数字用引擎跑一下定，写进说明。
- 没选题时，地图上用红色小旗标出**全港最塞的 5 段路**和**人多但离港铁远的 5 个分区**（「这里有问题」），点小旗看一句说明。

### 3. 结果说得清
- 跑完（稳定后）弹一张**成绩单**，用一句一句的白话：「新線每小時 3,617 人坐」「觀塘道少了 112 輛車」「啟德開車的人從 5.8 成降到 4.9 成」「全港塞車指標減少 75」——只用引擎给的数。
- 地图加「**變化**」图层：路按负荷变化着色（变少绿、变多红），分区按开车比例变化着色；一个「之前 / 之後」切换。
- 逐轮表保留，挪到成绩单的「详细」里。

### 4. 选分区调人数和吸引力（原任务 55 的内容）
点一格＝选中所属分区（Shift 加选），卡片上滑杆 −50%～+150%：整体人数；小孩 / 成人 / 老人（按 `trip-ends-2026` 的 HBS / HBW / HBO 占比改出发出行）；吸引力（到达 ×(1+x)，每个出发分区总出行不变）。改完「跑」看变化。检查：整体 +50%→出发 +50%；只调老人上学出行不变；吸引力改动出发总量不变；不调＝基准。

### 5. 数据面板
右栏页签「香港數據」：选中分区 / 路 / 站时显示真实数字，每个数后面标 **A 官方統計 / B 模型標定 / C 推算 / D 假設**（依据 `hk-base.json` 的 `sources`、`tiers`），底下一句话说明四级。
