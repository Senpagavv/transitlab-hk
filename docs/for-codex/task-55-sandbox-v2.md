## 二、做什么（P0）
1. **画风**：照 `v7/mode3-roads/ui.js` 的 `drawBase` 和 `v7/shared/style.css`：点纸、海、山 / 郊野公园（树丛）、像素房子按人口疏密、写字楼按岗位、淡色路带（塞的路中间红 / 橙线）、港铁官方色和站点。全港缩小时自动简化（只画区界、主干路、港铁），放大到能看清格子时才画房子和树。四种流量换底色（任务 51 的 `theme`）。
2. **分区选择**：点一格＝选中它所属的分区（`hk-base.json` 的 `zones[].cells`；没有就按格子最近的分区代表格），Shift 加选；选中的分区描边、旁边浮一张卡：名字、区、人口（分年龄）、岗位、早高峰出发 / 到达人次、开车比例。
3. **调人数和吸引力**（卡片上的滑杆，−50%～+150%）：
   - 「整体」：这些分区出发和到达的出行都按比例变；
   - 「小孩 / 成人 / 老人」：按这个分区各目的出行的占比去改出发的出行——小孩→上学（`HBS`），成人→上班（`HBW`）和其他，老人→其他（`HBO`）。目的占比从 `data/model/trip-ends-2026.parquet`（`P_HBW / P_HBS / P_HBO / P_NHB`）和 `landuse-2026.parquet`（`age_0_14 / age_15_24 / age_25_44 / age_45_64 / age_65_plus`）算，写进 `hk-base.json` 的 `zones[]`（需要回任务 51 的脚本加字段的话，在说明里写清楚，Claude 来合）。
   - 「吸引力」：到这些分区的出行 ×（1＋x），每个出发分区的总出行不变（从它去别处的出行里按比例匀出来）——就是重力模型「这里更吸引人」的意思。
   - 改完按「▶ 跑」逐轮跑到稳定（同任务 52 的规则），底下四个数和路况跟着变。
4. **数据面板**（右栏一个页签「香港數據」）：选中分区 / 一段路 / 一个站时显示它的真实数据，每个数后面一个小标：**A 官方統計**（人口、岗位、普查车流）、**B 模型標定**（早高峰出行、方式比例、路段负荷）、**C 推算**（晚高峰、平日日常）、**D 假設**（节假日、游戏换算）。标的依据用任务 51 `sources` / `tiers` 和 `model/registry/data_tiers.toml`。面板底下一句话说明四级是什么意思。
5. **三个子入口**（沙盘页顶上的页签）：「操控沙盤」（上面这些）、「查香港數據」（只看不改，数据面板放大）、「AI 出關卡」（先放一个输入框和按钮，调用 `v7/ai/client.js` 的 `TLAI.generate`，结果显示请求 JSON；切关卡和打开第三关由 Claude 接）。
