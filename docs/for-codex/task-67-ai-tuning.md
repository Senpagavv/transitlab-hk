# 任务 67：AI 出关卡调教准备（提示词、地点菜单、测试句）

> 分工：Codex 准备（**不能调 DeepSeek**），Claude 用真 AI 跑测试、和发起人一起调。10/18 前要。

## 一、现在的问题（Claude 真 AI 测出来的）
1. **AI 自己加改动**：句子只说「东涌要修一条新地铁线」，AI 也加了「逸東邨 住的人 +30%」「東涌站一帶 崗位 +30%」。句子没说的改动不要加。
2. **封路 / 隧道找不到**：「将军澳隧道维修封一条线」只能落到「將軍澳站一帶」——AI 的地点菜单只有分区名，没有路名、隧道名。
3. **地点不稳定**：同一句「启德多五万人」，一次选「啓德站一帶」，一次选「九龍灣站一帶」（后者 +5 万顶到 +150% 上限）。
4. **标题别扭**：如「將隧封線早高峰」。
5. 第三关切片 `cut.js` 里 `pct` 下限 −50，而后台 `road_cap` 允许 −60，会触发 invalid_request 重试（任务 59 发现）。

## 三、做什么
1. **只加句子里有的改动**：提示词写清楚「changes 只能来自句子明说的变化；没说就留空」；`validate()` 加检查（例如句子里没有数字或「多 / 少 / 增 / 减 / 封 / 建 / 卖地」类词却给了改动，要在 notes 记下）；加测试。
2. **路名、隧道名进菜单**：前端传给后台的 `names` 现在是「片区 → 分区名」；加上「片区 → 道路名（中文，按片区框内 `hk-base.json` 的 `roads`）」。`road_cap` 的 `place` 必须是道路名；`cut.js` 按道路名匹配（`roads.filter(r=>norm(r.name)===…)` 那一段核对一下中英文名都能对上）。把 `pct` 下限和后台统一（−50 或 −60 择一，两边一致）。
3. **地点别名表**：常见叫法 → 底板分区 / 片区（启德 → 啓德站一帶 / kai-tak；第一城 → 沙田…；北都 → northern-metropolis 但它框内没人口，要提示改用新田 / 古洞所在片区），放在后台，提示词里给 AI 用；加测试。
4. **标题**：4–10 个字、自然的中文、不缩写成怪词；提示词给好坏例子。
5. **测试句扩到 60 句**（`test-sentences.json`）：每句写期望的玩法、片区、改动（含「没有改动」的句子、封路句、卖地句、拒绝句）；`tools/ai-test/run_sentences.py` 加自动打分（玩法对不对、片区对不对、有没有多加改动、标题长度），输出一张表。Claude 用它跑真 AI。
