## 一、背景
发起人试玩 v7.11 后对第三关的意见：
1. **太容易**：塞的路已经画出来了，沿着红色的路画地铁，大概率就是高分。
2. **感受不到互动**：只看到车流变少，没有「跟车流来回较劲」的感觉——地铁让路通了，路通了又有人回去开车，这个来回要看得见、感觉得到。
3. **要图层**：能分别关掉「公共交通」和「道路车流」；同一条走廊上，车流和地铁画成**两条错开的平行线**，才看得清谁影响谁。

Claude 定的改法（四件事）：
- (a) 城市按年长，塞车的地方会挪——第 0 年最红的路不一定是第 8 年最红的；
- (b) 线分两期修：第 4 年后看到车流的反应，再补一刀（延长 / 加站 / 加车）；
- (c) 每年算出「新线让多少车下路」「路通了又有多少车回来开车」，画出来、说出来；
- (d) 点一段路，看这些车从哪来、到哪去（治本要在出发的地方给他们更快的选择）。

## 三、规则改动（engine.js / data.js）
现在的规则见 `engine.js` 开头注释（第二关全套 + 路 (车÷容量)² + 开车的人慢慢学 + 走路渐变 + 老线可换乘；分数＝每年「什么都不做」的塞车 − 今年的塞车，加起来）。这些都保留，加下面三件。

### 1. 城市按年长
- `data.js` 的屋苑 / 去处可以带 `grow:[[年,数],...]`（屋苑是 `people`，去处是 `attraction`），从第 0 年的值按直线插值，最后一个点之后不变。
- 起点建议（请用机器人调到满足下面的目标）：
  - 啟德 `people` 24 → 第 4 年 44（啟德新住宅入伙）
  - 順利·安達臣道 30 → 第 5 年 48（安達臣道入伙）
  - 將軍澳 70 → 第 6 年 80（日出康城）
  - 觀塘商貿區 `attraction` 26 → 第 6 年 30（起動九龍東，多了写字楼）
- 引擎：`year()` 用「这一年」的人数 / 吸引力（第 t 年运行时用 t 年的值）；起点的「以为的塞车」用第 0 年的值跑稳；`G.doNothing` 逐年也带增长。
- **调参目标**：什么都不做的塞车逐年明显上升（第 8 年 ≥ 第 1 年 × 1.4）；第 8 年最塞的两段路里，至少一段不在第 0 年最塞的两段里。

### 2. 分两期
- 第一期预算 20（第 0 年：画线、放站、列车，和现在一样）。
- 跑完第 4 年（`plan.year === 4`）自动停下：**第二期预算 +12**。只能加：从线的两头延长、在线上加站、加列车；第一期的东西不能拆；第二期加的东西在按「▶ 继续」之前可以撤回。然后跑第 5–8 年。
- 第二期新开的站，口耳相传照旧（按屋苑算，不另起）。
- `Plan` 加 `phase`（1 / 2）和第二期开始时的快照（判断哪些能撤）；`canExtend / toggleStation / addTrain / removeTrain / shorten` 按 `phase` 判断。`simulate()` 要能重放两期（方案里存第二期加了什么）。
- 分数算法不变。

### 3. 每年的「车流账」（`year()` 多返回）
- `roadBy[id]`：这段路上的车按来源分：屋苑 i → 去处 k、去处 a → 去处 b，各多少辆。
- `offRoad[id]`：**新线让多少车下路**＝同样的人数、同样「以为的塞车」、同样的知晓，但没有新线时这段的车 − 有新线时这段的车。
- `rebound[id]`：**路通了回来开车的**＝今年真的车 − 「有新线、但以为的塞车还停在开通那年」时这段的车（取正）。
- 再给两个总数。多跑两次 `year()` 就行；预览时可以不算（只在逐年运行时算）。

## 四、画面（ui.js / strings.js / roads.css，在 v7.11 版面上改）
1. **图层开关**：地图左下角（或「怎么看」图例里）两个开关「🚗 道路车流」「🚇 公共交通」，默认都开。
   - 关车流：路上的车流带、车点、塞车红 / 橙线不画（路本身的淡色底保留）。
   - 关公共交通：地铁线、站、坐地铁的点不画。走路的点一直画。
2. **平行错开**：路沿格子中线画淡色路带；车流画在路的一侧（偏 +6px，粗细 ∝ 这段的车；颜色按 (车÷容量)²：<0.5 灰、0.5–1 橙、>1 红）；地铁线和路走同一段格子时，画在路的另一侧（−6px），粗细 ∝ 这段坐的人；不和路重合的地铁段照常画在格子中间。可以参考 `mode4-bus/ui.js` 的 `offAt`（巴士和车已经这样错开过）。
3. **点一段路**（地图上点，或右边路况里点路名）：
   - 地图上只亮「车在这段路上的」屋苑和去处，其他变淡；把这些车的整条路线描一下。
   - 右边「路况」里这一段展开：今年 N 辆（容量 C）；最多的三股（「秀茂坪 → 觀塘 22」）；「新线让 X 辆下路 · 路通了 Y 辆回来」；一个小折线：逐年这段的车（实线＝你的方案，虚线＝什么都不做，下一年灰色预告）。

4. **每年一句**（右上那句）：优先说最大的来回——「觀塘道：新线让 62 辆下路，路通了 18 辆又回来」；长的那年说「第 3 年 啟德入伙：多 X 人出门」；第 4 年停下时说「第二期：预算 12——看看车流挪到哪了」。
5. **会长的地方**：地图上挂一个小牌「+20 · 到第 4 年」，长完就去掉；长的那年这个屋苑闪一下。
6. **第二期**：控制列显示「第二期 · 预算 12」；线的卡片和详情框重新能点，只能加；「▶ 继续」。
