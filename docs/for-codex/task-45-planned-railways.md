# 任务 45：整理香港政府已公布的规划铁路（教学与游戏的「现成方案」）

## 一、背景
TransitLab HK 的教学 / 游戏模式里，用户可以先打开**政府已公布的规划铁路**，看它对全港和自己住的地方有什么影响，再自己修改。
你要把这些线路整理成一份带出处的清单，加上**大致走向和车站位置**（地图上能画出来的程度）。

## 二、硬规矩（违反作废）
1. **项目只读**：`F:\transitlab-hk` 里不写、不改、不删任何文件。
2. **只写一个目录**：`%USERPROFILE%\Desktop\TransitLab规划铁路\`（不存在就创建）。
3. 可以上网查公开资料（运输及物流局、路政署铁路拓展处、港铁、立法会、北部都会区网站、《香港主要运输基建发展蓝图》2023、《跨越 2030 年的铁路及主要干道策略性研究》），**不要批量抓取政府网站**。
4. **不编造**：车站位置来自官方示意图时，坐标是你在地图上读出来的**近似位置**，必须标「近似，读自某某示意图第几页」；查不到的写「未公布」。

## 三、要整理的内容
1. **清单**：每条线一行——名称（中、英）、状态（已动工 / 已批准 / 规划中 / 研究中）、起讫、途经、长度（公里）、车站数和站名、预计造价与价格年份、预计通车年份、
   连接哪些现有线路（换乘站）、主要服务的新发展区、出处（文件、页码、网址）。
   至少包括：北环线（主线、东延）、港深西部铁路（洪水桥至前海）、屯门南延线、东涌线延线、洪水桥站、古洞站、小蚝湾站、
   北都相关的中铁线 / 中央铁路（如有官方名称以官方为准）、蓝图中提到的其他铁路及集体运输系统（如智能绿色集体运输系统）。以官方文件实际列出的为准，有就列，没有就不列。
2. **几何**：每条线一个 GeoJSON `LineString`（WGS84 经纬度），每个车站一个 `Point`，属性包括 `line_id`、`name_zh`、`name_en`、`status`、`approx`（是否近似）、`source`。
   位置读不准就宁可少放点，并在属性里写 `approx: true` 和精度说明（例如"±300 米"）。
3. **注意事项**：哪些线路的走向官方只给了示意、可能改动；哪些数字是旧文件的、已被新文件取代。

## 四、产出（`%USERPROFILE%\Desktop\TransitLab规划铁路\`）
| 文件 | 内容 |
|---|---|
| `规划铁路清单.md` | 主文档（中文），附英文线路名 |
| `planned_railways.geojson` | 线路和车站 |
| `sources/` | 下载的官方文件 |
| `核对记录.md` | 每条线、每个站的出处和页码；近似位置怎么读的 |

## 五、完成后
回复一句话：整理了几条线、几个站，几个位置是近似的，哪些资料没找到。
