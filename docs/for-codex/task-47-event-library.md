# 任务 47：游戏「大事件库」（限时化解的题目素材）

## 一、背景
修地铁游戏改成「城市出了大事，你用铁路和车站（TOD）在限时内化解」（见 `docs/design/game-v3-concept.md`）。
每局一个事件：一个清楚的问题、一个目标、一个时限；时间压缩（现实要十几年的规划，几分钟内做完）。
发起人举的例子：**某区「吸血鬼爆发」，要把这区的人快速转移出去**——只修一个站，大家都挤那一个站，转移反而慢，所以要几个站分流、和现有线路配合、找平衡。
你要整理 **10–12 个事件**，每个都写清楚数量依据，让我们能直接做成关卡。

## 二、硬规矩（违反作废）
1. **项目只读**：`F:\transitlab-hk` 不写、不改、不删（可以读、可以 import 运行）。
2. **只写一个目录**：`%USERPROFILE%\Desktop\TransitLab大事件库\`。
3. 可以上网查公开资料（港铁、运输署、入境处、康文署 / 启德体育园、天文台、立法会文件、新闻报道），**不要批量抓取政府网站**。
4. **不编造**：真实数字写出处和页码 / 网址；虚构事件（吸血鬼、僵尸之类）**明确标「虚构」**，但其中的人口、站容量、线路运力必须用真实数据或项目数据；推算的写清楚怎么算的。

## 三、项目里能用的真实数据（只读）
```python
import sys; sys.path.insert(0, r"F:\transitlab-hk")
from game.engine.base import get_base; from game.engine.places import get_places
b, pl = get_base(), get_places()
```
- 每个分区的人口、岗位：`pl.zones`（`zone, label, district, pop, jobs, lon, lat`）；任意一点 800 米内住多少人：`pl.probe(lon, lat)`
- 早高峰分区到分区坐公交的人：`b.peak0["P_PT"]`（470×470，`b.ids` 顺序）
- 港铁每段早高峰人数和载客率：`data/model/transit-assignment-am-2026.parquet`
- 口岸每日出入境人次：`data/raw/` 下入境处数据（见 `docs/data-sources.md` H01）

## 四、每个事件要写
| 字段 | 说明 |
|---|---|
| 名称（中 / 英）、一句话剧情 | 例：「启德演唱会散场：5 万人 1 小时内要回家」|
| 真实 / 虚构 | 虚构的写明 |
| 地点 | 区、分区编号或经纬度（几个点）|
| 多少人、多长时间 | 数字 + 出处或算法（例：启德主场馆座位数 × 上座率）|
| 改变了什么 | 需求暴增（从哪到哪多少人）/ 某线停运 / 某站关闭 / 道路封闭 / 人口迁入 |
| 目标（怎么算赢）| 一句话，可量化，例如「30 分钟游戏时间内转移 90%」「最挤的站排队不超过 15 分钟」|
| 为什么一个站不够 | 瓶颈在哪：站的进出闸 / 月台容量、列车运力、换乘站、道路 |
| 需要的容量参数 | 例：港铁一个站每小时进出闸能力、月台能容纳多少人、每列车运力；查不到写「未找到」|
| 评分维度 | 从 速度 / 花费 / 拥挤 / 公平 / 环保 里选，各怎么算 |
| 现实里类似的事 | 例：2019 年某线停运、跨境高峰日、八号风球后复航 |

**至少包括**：吸血鬼（或僵尸）爆发疏散（虚构）、启德体育园大型活动散场、台风后某条线停运（东铁或屯马）、跨境口岸节假日人潮、北都新屋苑集中入伙、东铁线早高峰过挤、老龄化屋苑出行（长者步行范围小）、新就业中心开张（例如河套 / 洪水桥）、海底隧道或过海铁路中断、大型展览（会展 / 亚博）。
