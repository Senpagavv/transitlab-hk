# 界面问题清单

规则：**影响操作的现在改；美观类（颜色、字体、间距、动画、排版）记在这里，第 4 周（10/18 前）集中处理。**

## 已修复

| 日期 | 问题 | 处理 |
|---|---|---|
| 2026-09-15 | 搜索要等很久才出结果 | 新增本地车站/站点索引，打字即出（约 10–50 ms）；政府接口复用连接并缓存 |
| 2026-09-15 | 必须点"搜索"按钮，缺少引导 | 去掉按钮，边打字边出下拉联想；支持方向键选择、回车确定、Esc 关闭、× 清空 |
| 2026-09-15 | 删除文字后下拉栏不消失 | 下拉栏与输入框同步：文字清空、点击外部、选中结果时淡出消失 |
| 2026-09-15 | 放大地图后红点变得很大、挡视野 | 标记改为固定屏幕像素大小（任何缩放级别都一样大） |
| 2026-09-15 | 快速放大时出现又大又糊的旧图片，过一会儿才替换 | 底图从图片瓦片换成地政总署矢量底图（文字始终清晰，16 级以上不再下载）；快速放大时用淡化的低清底图占位，避免整屏空白 |

| 2026-09-15 | 缩放/拖动时加载慢、出现灰屏和莫名的马赛克碎块 | 先解决速度：后端本地瓦片缓存（看过的地方约 0.3–0.5 秒就绪）+ 解析线程 1→4；过渡简化为"缩放时盖旧画面、就绪后整体一次碎开"，拖动不触发 |

| 2026-09-15 | 第一次看某个地方仍需约 1.2–1.9 秒 | 用户选择预下载全港瓦片（限速，约 1 小时）；另做 PMTiles 打包供上线使用 |

## 考虑过但不做

| 想法 | 原因 |
|---|---|
