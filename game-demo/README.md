# 修桥 / 修地铁试算（小 demo）

**本地玩**：双击 `index.html`（修桥）或 `metro.html`（修地铁），不需要服务器（要联网，因为底图瓦片来自地政总署）。

**放到网上**：把整个 `game-demo` 文件夹原样上传到任意静态网站（GitHub Pages、Netlify、Vercel、对象存储都行），入口是 `index.html`。

**数据更新**：模型重跑后，在项目根目录执行
`.venv\Scripts\python.exe game-demo/build_data.py`，重新生成 `data*.js`。

| 文件 | 是什么 |
|---|---|
| `index.html` / `app.js` | 修桥页：点两下修桥（桥头吸附到最近的真实路口）、拖动桥头、上色、画出车真实开的路线 |
| `engine.js` | 修桥的计算：谁会走、省多少时间、造价、回本年数；单价在文件顶部 |
| `metro.html` / `metro.js` | 修地铁页：双击按住画线、自动排站、拖站、开始算、一轮轮动态显示、图层切换 |
| `sim.js` | 地铁的迭代计算：公交时间（含拥挤）→ 去哪/坐什么 → 人口搬迁 → 路上重新分配车流，逐轮平均到稳定 |
| `road.js` | 两页共用的早高峰真实路网：最短路（正向/反向）、吸附到路口、还原路线 |
| `land.js` | 两页共用的陆地 / 水面判断（海、水塘不能走，见下面「不可通行区域」） |
| `style.css` | 两页共用样式 |
| `data.js` / `data-metro.js` / `data-road.js` / `data-land.js` | 模型数据（455 个分区、开车/公交时间表、车流人次、路网和路口坐标、中文路名、哪些路口能接新桥、约 40 米的陆地/水面格），由 `build_data.py` 生成 |
| `data-sources.json` | 这些数据来自哪 17 个原始文件，以及它们的指纹（SHA-256） |
| `tests/passability.test.js` | 不可通行区域的自动检查（见下） |
| `vendor/` | 地图库 Leaflet 1.9.4 |

**原始数据不会被污染**：`build_data.py` 只读 `data/`，只写 `game-demo/`（写到别处直接报错），读前读后比对指纹；网页只在浏览器内存里算。
另有只读快照 `data/snapshots/`，用 `.venv\Scripts\python.exe scripts/snapshot_base_data.py --check` 核对现在的数据和快照是否一致。

**不可通行区域（海、水塘）**：陆地/水面来自规划署 2024 土地用途 10 米格网（`pipeline/36`），和模型里「分区接到路网、接到车站不能跨水」是同一个标准。
- 修桥：桥头点在海上不放；只接在陆地上的地面路口（不接桥面、天桥、隧道、收费广场、快速公路），而且点的地方和路口之间不隔海；2 公里内没有能接的路（不通车的离岛）就提示换地方。拖到海上会弹回原处。
- 修地铁：线可以过海（海底隧道），站不行。线头伸进海里自动收回岸上；自动排的站落在海上就沿线挪到最近的岸上，挪不了就不设；拖站拖到海边就停住；点海上的线段不加站。
- 走路进站：直线上连续的水超过 80 米就算走不过去（维港最窄的鲤鱼门也有 300 多米）。

自动检查：项目根目录 `node --test game-demo/tests/passability.test.js`（`uv run pytest` 也会跑）——随机撒 1500 个点试桥头、维港两岸/鲤鱼门/南丫岛/马湾/水塘这些以前容易出错的地方、两页的例子、维港两岸随机 400 个站的走路范围。

截图检查：`cd frontend; node scripts/check-bridge-demo.mjs map-check/bridge`
