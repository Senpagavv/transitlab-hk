# TransitLab HK · 独立互动关卡

这些页面是为现场演示准备的静态备用入口，每关可以单独打开，手机宽度下自动换成单列布局。页面中的绿色圆环以真实百分比绘制：100% 为整圈、50% 为半圈、80% 为 80% 圈。

- `index.html`：四关入口与演示顺序
- `mode1.html`：车站与步行，独立互动演示、无需注册、不计入排行榜；`mode1-poster.html` 为纯静态备用图
- `mode2.html`：地铁，展示线路、班次、预算
- `mode3.html`：道路拥堵，展示早高峰 V/C 与分流
- `mode4.html`：站旁开发，独立互动演示、无需注册、不计入排行榜；`mode4-poster.html` 为纯静态备用图
- `ring-verification.html`：校验 0/50/80/100% 与绿圈弧长对应关系

`mode1.html` 与 `mode4.html` 不读取或写入账号、排行榜，也不会发起网络请求；打开文件即可展示。第一关可以选择/拖动 A、B、C 站，或选择站点后直接点击地图放站，再按「运行一轮」；第四关可以点击地图放置车站，选择住宅/商店后点击空地，再按「运行下一年」。所有绿圈都使用同一个百分比来源：100% 整圈、50% 半圈、80% 五分之四圈。原有 `mode1-bus` 至 `mode4-tod` 互动页面保持不变。
