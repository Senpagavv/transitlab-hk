现场备用入口 · 01–04

独立互动关卡

第一关和第四关可以单独打开并正常操作，适合手机或现场演示；不需要注册，也不会写入排行榜。绿色圈和百分比严格对应。

推荐演示顺序先看 01 车站与步行，再进入 05 大沙盘完成“改人口 → 划线 → 运行数据”。
01

接驳巴士，把人接上车

选择 A / B / C 站，点击棋盘放站或移动站点，再按“开始”运行一轮，观察公交、人流和按百分比绘制的绿色圈。无需注册。

02

一条新线，打开新界西北

把屋苑和工作地点连上地铁，比较步行距离、班次和预算。绿色圈表示需求被轨道交通吸收的比例。…

03

道路会塞，也可以被重新分流

在九龙东的路网中调整道路和公交接驳，观察早高峰车流、地铁分担率和瓶颈位置。…

04

站旁开发，让目的地更近

先画线，再切换“放站”点击地图放置车站；还可以卖住宅或商业用地，按“下一年”观察客流、收入和开发变化。无需注册。
