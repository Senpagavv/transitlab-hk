Five modes五個模式

從一座車站開始，一層一層加上真實城市的規則：地鐵、塞車、地面巴士，最後是整個片區的沙盤。

MODE 01車站與步行

人願意走多遠、怎樣分去幾座站、站會不會爆。四關：朗屏（引導）、元朗南、粉嶺、大埔墟。

可以玩 → MODE 02地鐵

畫一條線、放站，再經營六年：換的成數＝比開車省的格數＋經驗常數；車廂擠了，經驗就降。
