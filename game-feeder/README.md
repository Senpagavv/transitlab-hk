# 接駁巴士小遊戲（入门关）

把朗屏四个屋苑原本开车的人，用三座接驳站和定时巴士送上港铁。这是「入门游戏 → 互动教学 → 全港沙盘」路线里的第一关，教的是：走路距离、班次和运力怎样决定大家坐不坐公共交通。

## 怎么玩 / 怎么改

- **玩**：双击 `v2/开始游戏.html`（单文件，离线可玩；联网时会加载品牌字体）。桌面快捷方式「接驳巴士 v2」指向它。
- **改**：改 `v2/` 里的 `engine.js`（规则）、`data.js`（地图和需求）、`ui.js` / `style.css` / `index.html`（画面），然后 `python v2/build.py` 重新生成 `开始游戏.html`。
- **测规则**：`node v2/test_engine.js`（13 项）。
- **AI 试玩**：`node bots/evaluate.js v2 --write`（或 `v1-codex`），报告写到 `bots/reports/`。调参搜索：`node bots/sweep.js`。
- **截图 / 指定局面**：网址后加 `#intro=0&layout=0-7-11&t=400&hover=3&sel=1&moves=125:1:11`（数字是 `data.js` 里候选格的序号）。

## v2 规则（一句话版）

1. **离站越远越少人来**：走 0–1 格 100%，之后每多 1 格少 20%，6 格以上没人来。圈上显示的比例就是真的会来的比例。
2. **离港铁越近班次越密**：班距 = 60 秒 + 到港铁每格 10 秒；每班 6 座，另有 8 个排队位；挤不进、等太久的人回家，改去别的站或开车。
3. **潮汐表**：每 2 分钟一批，平时唐人新村每批 6 人、其他每批 3 人；每个屋苑一次高峰（多 15 人）。可以搬站 6 次，每次重建 20 秒。

过关 120（送达三分之二），高分 135（要在高峰前搬站）。所有数字是游戏设定，不是香港实测。
