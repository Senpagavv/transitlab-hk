# 接驳巴士长局观察版

直接双击同文件夹的 `开始游戏.html`。默认 1×，一局固定 18 分钟，初始布局时间和暂停时间不计入。无安装、无网络依赖。

玩法：用三座公交接驳站把乘客送到固定的朗屏港铁终点，送达每人 +1 分。120 分为观察目标，130 分为高分参考；它们是本固定需求样本的调参基准。首次可点「试放三座站」观察近住宅布局的拥挤，再尝试改变站位。香港地点与相对方位保留，棋盘道路和 240 人需求均经过游戏化处理。

## 本版和旧版的关键区别

- 默认 18 分钟；第 1 批 00:35，其后每 2 分钟一批，共 8 批 × 30 人。每批在 30 秒内陆续离家。每个住宅的总人数、本批剩余、下一批人数和时间直接画在住宅卡上，点卡可看八批表。
- 接驳车从站点定时出发。到站有空座就进入下一班车，满 5 座后排队，另有最多 8 个排队位。满座不会立即发车，必须等发车倒计时；倒计时到零即发车，下一班随即开放入座。空班不画行驶动画。
- 每站代表一项接驳服务，班距抽象整个车队的周转，不是“每站仅一辆车，回来才能上客”。不显示空班与返回动画，仍按时耗用这一班服务窗口，没有乘客时不会攒下额外班次。
- 地图只显示载客车单向「接驳站 → 朗屏港铁」，车 A、B、C 身份不变，箭头按道路实际方向绘制。没有动画往返；车队返回、准备和运力抽象为班距。
- 靠近住宅：步行短，吸引更多人，但可能聚集拥挤。靠近港铁：步行长，班距更短。每人意愿固定，距离逐渐衰减；候车和现有队伍共同降低吸引力。不是“一圈内所有人必来”的硬阈值。
- 满员或久候者步行返家，返家后尚有耐心时可再考虑一次；已自驾不可追回。搬站共 6 次，重建 20 秒。尚未发车的入座者与排队者返家，已发出的车沿原路线送达，在途行人可转向其他站。
- 18 分钟结束时，剩余人员记为「未完成」，不冒充自驾或减碳成绩。结算可保存 JSON 本局记录，包含事件、搬站时间和参数，方便下次调整。

## 时间与容量

| 项目 | 设置 |
|---|---|
| 每班座位 / 额外排队位 | 5 / 8 |
| 班距 | 70 秒 + 站点到港铁道路格数 × 12 秒 |
| 首班 | 开局后等一个完整班距；搬站后从重建完成重新计班距 |
| 单程巴士 / 步行 | 每格 10 秒 / 12 秒 |
| 在家考虑上限 | 50 秒，每 4 秒评估一次 |
| 站内候车耐心 | 每人固定 110–130 秒，包括入座后尚未发车的时间 |
| 总耐心 | 离家准备开始算，190–230 秒，返家和搬站不重置 |
| 返家后再考虑 | 至多 50 秒，受剩余总耐心限制；每人最多出发尝试两次 |

吸引力的实现：`距离项 × 候车项 × 拥挤项`。

```
距离项 = 1 / (1 + (道路步行格数 / 3.8)^2)
候车项 = 1 / (1 + (到站后预计等待发车秒数 / 140)^2)
拥挤项 = 1 / (1 + 当前排队人数 / 10 + 当前入座人数 / 25)
```

各乘客有固定的意愿阈值 0.08–0.80，选择超过阈值且最有吸引力的站。预计到站已错过发车时，会考虑下一班；若总耐心不足以走到并等待该班，则不选择该站。拥挤项只看当下站内人数，不预知所有在途行人，因此仍可能同时到站挤满。悬停光圈与「距离吸引强中弱」只说明距离项，不是实际搭乘率。

## 给下一位 AI 或开发者

- `data.js`：四住宅坐标/名称、棋盘道路、13 个候选点、八批人数。原始模型量已缩放再放大，不代表香港实测人流。
- `engine.js`：独立离散时间规则，`P` 是调参入口，固定种子 1781，0.5 秒步长。包含个人状态、队列、班距、单向车程与搬站。
- `ui.js`：SVG 地图、悬停与键盘预览、住宅卡、暂停/速度、结算、记录下载。
- `style.css` / `logo-tide.svg`：品牌 UI，保留组员标志。字体使用系统回退，未打包商业字体。
- `index.html`：开发入口。`build.py` 内嵌 CSS、JS、SVG 到 `开始游戏.html` 并生成同级 ZIP；修改源文件后须重建，勿只改内嵌产物。
- `test_engine.js`：规则断言、286 份固定布局对照、1050 份单次搬站策略对照。运行 `node test_engine.js` 更新 `验证结果.json`，运行 `python build.py` 打包。

模拟对照能验证拥挤与取舍存在，不能证明真人觉得好玩。下一步按完整长局试玩反馈调整：等班是否过久、哪批最难判断、返家是否易读、搬站是否值得。先缩短节奏或调运力，不同时改多组关系。动态策略样本只搜索一次搬站，并非六次搬站的全局最优解。

这版只表达公交接驳可达性、运力与交通方式选择，尚不包含完整 TOD 土地使用模型，也不将得分换算真实碳减排。
